Outreach Message Builder

Companion tool — turns your researched tracker rows into ready-to-send outreach messages, tailored per company.

Third tool in this family. The Target Company Prompt Builder researches and ranks companies. The Job Posting Finder checks who's actively hiring. This one takes your shortlist — with its Key Contacts, Warm Introduction Path, and Category already researched — and drafts the actual messages, so you're not starting from a blank box.
1 · Paste from your tracker optional

Ctrl+click (or Cmd+click on Mac) lets you select non-adjacent columns in Excel and copy them together, tab-separated, in the order you clicked. That's what this box expects: Company, then Key Contacts, then Warm Introduction Path, then Category.

No paste at all? Click above to build a row from scratch — company, contact, warm intro path, category, and target audience, one at a time.

2 · Message settings

LinkedIn connection requests have a strict ~300-character limit — the generated prompt enforces this automatically when selected.

Same field as the other tools in this family — reused here so messages reference your actual background where relevant, not filler.

3 · Output
Why the reasoning is always shown: for every company, the output explains which approach it picked and why — e.g. "leans on shared history since Warm Introduction Path names a former colleague" vs. "opens with relevance since there's no existing connection." This isn't optional — it's how you catch it if the tool read a Warm Introduction Path wrong, before you send anything.
Grounding guardrail: the generated prompt explicitly tells Claude not to invent shared history, mutual connections, or personal details that weren't actually provided — every message stays grounded in your real background and the tracker's actual research, even if that means a more generic (but honest) opening for a cold company.
